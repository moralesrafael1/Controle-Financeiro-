# Controle Financeiro Inteligente

Um aplicativo web projetado para automatizar e simplificar a gestão financeira pessoal. O objetivo principal do projeto é permitir que o usuário faça o upload de imagens de cupons e notas fiscais, enquanto uma Inteligência Artificial lê, extrai e organiza automaticamente os gastos.

## Status do Projeto
Em desenvolvimento. A interface visual básica já está construída e o projeto está recebendo novas funcionalidades gradativamente.

## Funcionalidades Atuais
- **Upload de Imagens:** Interface preparada para o envio de fotos de recibos e cupons fiscais.
- **Painel de Resumo:** Visualização inicial dos dados processados.

## Próximos Passos (Roadmap)
As seguintes funcionalidades estão planejadas para as futuras atualizações:
- [x] Integração com IA para leitura automática das notas fiscais (OCR).
- [] Aprimorar formato de recebimento dos dados.
- [] Análise inteligente de padrões de consumo.
- [] Sistema de login e autenticação de usuários.
- [] Cadastro manual de receitas e despesas extras.
- [] Geração de gráficos dinâmicos para visualização do fluxo de caixa.

## Tecnologias Utilizadas
O projeto está sendo construído com as tecnologias fundamentais da web, sem a necessidade de frameworks complexos no momento:
- **HTML5:** Estruturação da página.
- **CSS3:** Estilização e layout da interface.
- **JavaScript:** Lógica de funcionamento e interatividade.
